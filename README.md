# WoofCash yard

Live arena UI for **WoofCash ($WOOFCASH)** on Robinhood Chain.
Paired with $AI. Launch venue: Long.xyz.

## Import on Vercel

This is the repo to import into [vercel.com/woofcash](https://vercel.com/woofcash).

1. [vercel.com/new](https://vercel.com/new) → Import `woofcash/yard`
2. Framework **Vite**
3. Build command `npm run build`
4. Install command `npm install`
5. Deploy, then attach `woofcash.xyz`
